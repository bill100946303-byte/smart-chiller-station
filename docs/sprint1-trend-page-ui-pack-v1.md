# Sprint1 趋势分析页 UI Pack v1

## 结论

- 是否达到“首版可联调可演示”：`yes`
- 结论前提：沿用现有 `TrendAnalysisPage + TrendPanel + StatCard + SectionCard + SourceStatusBanner` 组件体系，不扩复杂分析能力，只把页面结构、状态落点和交互层级收口。

## 页面目标

趋势分析页首版只回答 3 个问题：

1. 当前站点在所选时间范围内，关键运行指标整体是上升、回落还是波动。
2. 哪几条序列当前可用，哪几条存在陈旧、降级或缺口。
3. 值班同学在图表不可用时，是看数据问题、来源问题，还是单纯没有命中当前筛选。

## 页面模块拆分

### 1. 顶部摘要区

- 模块名：`TrendAnalysisHeader`
- 内容：
  - 页面标题、副标题
  - 来源状态条 `SourceStatusBanner`
  - 时间范围切换 `RangeSwitch`
  - 一行页面级说明文案
- 作用：
  - 先确认链路是否通，再看范围，再进入图表。

### 2. 关键统计卡区

- 模块名：`TrendSummaryStrip`
- 组件：4 个 `StatCard`
- 建议卡片：
  - 总站功率
  - 冷站 COP
  - 冷冻水温差
  - 冷却水温差
- 作用：
  - 用“当前值 + 小状态 pill”回答“现在怎么样”。
  - 不承载趋势细节，避免和图表重复。

### 3. 主图表区

- 模块名：`TrendChartSection`
- 组件：
  - `SectionCard`
  - `TrendPanel`
  - 图表头部最小筛选条 `MetricFilterChips`
- 内容层级：
  - 第一层：区块标题 + 次级说明
  - 第二层：最小指标筛选 chips
  - 第三层：多序列折线图
  - 第四层：图例 + 最新/最小/最大
- 作用：
  - 这是页面主角，回答“这段时间发生了什么变化”。

### 4. 序列统计侧栏

- 模块名：`TrendSeriesStatRail`
- 组件：
  - `SectionCard`
  - 纵向统计项列表
- 内容：
  - 每条有效序列的 latest / min / max
  - 可选补一条“有效点数 / 连续性”提示
- 作用：
  - 承接主图表的阅读，不挤占图表空间。
  - 当桌面端需要快速对比多序列时，比把说明都塞进图例更清楚。

## 图表区与摘要区关系

- 摘要区回答“现在值是多少”，是首屏判断入口。
- 图表区回答“在所选范围内怎么变”，是主分析区。
- 侧栏统计回答“每条序列稳定性如何”，是图表的解释层。

页面阅读顺序固定为：

1. 来源状态
2. 时间范围
3. 4 张摘要卡
4. 主图表
5. 序列统计

不要把图表放在摘要卡前面。趋势页不是“先看图再猜现在值”，而是“先看当前态，再看变化原因”。

## 过滤 / 范围交互位置

### 时间范围切换

- 位置：页头右上，与标题同一水平带。
- 形式：`24h / 7d / 30d` pill button。
- 原则：
  - 范围切换是页面级交互，只出现一处。
  - 切换后同步影响摘要卡、图表、侧栏统计。

### 最小指标筛选

- 位置：主图表卡头，位于标题下方。
- 建议选项：
  - 全部
  - 功率
  - COP
  - 温差
- 原则：
  - 这是图表级筛选，不影响顶部摘要卡。
  - filtered empty 只作用在图表卡内，不提升为整页异常态。

## 首屏布局（桌面端优先）

### Desktop >= 1180px

- 第一行：页头标题区 + 右侧范围切换。
- 第二行：来源状态条全宽。
- 第三行：4 列摘要卡。
- 第四行：
  - 左 8 列：主图表区
  - 右 4 列：序列统计侧栏

### Tablet / Small Desktop 900px - 1179px

- 页头改为上下堆叠，范围切换移到标题下方。
- 摘要卡改为 2x2。
- 主图表与侧栏改为上下堆叠。

### Mobile < 900px

- 来源状态条保留，但 detail 默认折叠。
- 范围切换保留一行，按钮可换行。
- 摘要卡改为单列或双列。
- 主图表保留，序列统计改为列表卡片堆叠在图表下。
- 图例不再横向铺满，改为两列以内，避免横向滚动。

## 状态落点

### normal

- 来源状态：`good`
- 摘要卡：正常值 + live / aggregated pill
- 图表区：显示多序列趋势图 + 图例
- 侧栏：显示有效序列统计

### degraded

- 来源状态：`warn`
- 页面级：来源状态条说明哪条来源不可用
- 图表区：显示 degraded hint
- 摘要卡：仍展示可用值，不强制整页置灰
- 侧栏：仅显示仍有值的序列；缺失项显示 unavailable copy

### stale

- 来源状态：可 `good` 或 `warn`，但页面需出现 stale 提示
- 图表区：在图表头部或图表上方显示 stale banner
- 摘要卡：pill 改为 stale
- 页面不应白屏，用户仍可读到最近一次有效快照

### empty

- 触发条件：趋势端返回空序列，且没有任何有效统计项
- 图表区：显示空态说明
- 侧栏：显示“当前未返回可展示统计摘要”
- 页面级不判失败，除非同时伴随 degraded 来源异常

### filtered empty

- 触发条件：页面有趋势数据，但当前图表筛选下无有效序列
- 落点：只在主图表区显示
- 文案建议：
  - 当前筛选条件下暂无有效趋势序列
  - 可切换到“全部”或其他指标分组继续查看
- 不能误导成上游异常，也不能把来源状态条改成 warn

## 组件复用建议

### 可直接复用

- `SourceStatusBanner`
- `SectionCard`
- `StatCard`
- `TrendPanel`
- `StatusPill`

### 页面级新增建议

- `TrendAnalysisHeader`
- `TrendSummaryStrip`
- `MetricFilterChips`
- `TrendSeriesStatRail`

新增都应是页面拼装层，不要重新发明新的卡片体系。

## 与驾驶舱关系

- 驾驶舱趋势区是“摘要型趋势”。
- 趋势分析页是“分析型趋势”。
- 两者必须复用同一套范围、状态词和图表视觉语言，但趋势分析页要把图表放在更高优先级。

## 不做项

- 不做复杂对比分析
- 不做跨设备 drilldown
- 不做导出
- 不做注释
- 不做联动到 2D/3D 场景
- 不做高级筛选器

## 开发收口建议

- 先保留现有 `24h / 7d / 30d` 范围切换。
- 首版只新增最小指标筛选，不做多维筛选面板。
- 图表卡负责 `normal / degraded / stale / empty / filtered empty` 五类状态，不把所有异常都抛到整页。
- `TrendPanel` 继续作为核心图表承载组件，避免新开一套图表壳。

## 最终建议

- 建议进入开发：`yes`
- 理由：
  - 现有壳层组件已经能覆盖首版 70% 以上结构。
  - 多序列趋势图已经具备基础承载能力，剩余是页面拼装和状态口径收口。
  - 本版范围明确，没有把趋势页做成复杂分析平台，适合 Sprint 1 联调与演示。
