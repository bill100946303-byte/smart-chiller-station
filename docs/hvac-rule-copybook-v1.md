- 前端模块：Dashboard / System Overview 的规则诊断与建议卡
- 目标：统一中文话术，不改规则逻辑、不改阈值判定

版本信息：

- ruleSetRef: `hvac-rules-v1@1.0.1`

## 2. Skipped 场景中文话术模板

说明：
- 下列模板用于“规则未执行/被跳过”提示区。
- 可按页面语气选择一条，避免重复堆叠。

### `upstream_unreachable`
1. 上游数据源暂不可达，本条规则已跳过；请先恢复 BFF/legacy 连接后重试。
2. 当前采集链路中断，规则判定暂停；建议先检查服务健康与网络连通性。
3. 未获取到可用上游数据，无法完成诊断；请确认 8098/8787 端口与接口状态。

### `field_missing_or_invalid`
1. 缺少规则所需关键字段或字段值无效，本条规则已跳过。
2. 指标数据不完整（空值/非法值），暂不输出诊断结论；请补齐采集映射。
3. 规则输入字段校验未通过，建议先排查字段口径与单位映射。

### `unknown`
1. 本条规则暂未完成解释映射，请联系运维查看原始规则日志。
2. 规则状态未识别，系统已安全降级为“仅展示基础信息”。
3. 当前诊断类型未知，建议先核对规则版本与前端词典版本是否一致。

## 3. 风险等级中文规范（统一标准）

原则：
- 同一页面同时展示 `severity` 与 `risk` 时，必须使用同一套中文规范。
- 禁止出现“高风险/严重/重大”混用无定义场景。

### `risk` 映射（风险概率与影响综合）

| 英文值 | 中文 |
| --- | --- |
| `high` | 高风险 |
| `medium` | 中风险 |
| `low` | 低风险 |

### `severity` 映射（当前事件严重程度）

| 英文值 | 中文 |
| --- | --- |
| `critical` | 紧急 |
| `major` | 重要 |
| `minor` | 提示 |

统一展示建议：
- 推荐卡主标签优先展示 `risk`（高/中/低风险）。
- 详情区补充 `severity`（紧急/重要/提示）。

## 4. 前端接入建议

接入优先级：
1. 先做本地词典映射：按 `ruleId` 与 `skippedCategory` 直接替换中文文案，保证稳定可读。
2. 再补 message 明细：将后端 `evidence/actions/reason` 与本地模板合并展示，增强解释性。

兜底文案：
- 当 `ruleId` 未收录：
  - 标题：`规则诊断（未命名）`
  - 说明：`该规则已触发，但当前版本暂无中文说明，请查看证据详情。`
  - 建议：`请联系运维确认规则词典是否需要更新。`
- 当 `skippedCategory` 未收录：
  - `当前规则暂不可执行，系统已降级处理，请稍后重试。`
