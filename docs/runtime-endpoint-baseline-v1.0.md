# Runtime Endpoint Baseline v1.0

## 1. 目标与边界
- 目标：固化本地运行时入口与端口基线，供联调、巡检、发布后排障统一使用。
- 边界：仅定义运行时入口与端口，不涉及业务字段、字段口径、`null_strategy`、规则计算逻辑。

## 2. 端口与入口基线

| 系统层 | 服务名 | 端口 | 基线入口 |
| --- | --- | ---: | --- |
| Frontend | 前端 Shell | 3001 | `http://127.0.0.1:3001/` |
| BFF | chiller-bff | 8787 | `http://127.0.0.1:8787/` |
| Legacy | legacy backend | 8098 | `http://127.0.0.1:8098/` |
| 2D/3D | 2D/3D 场景服务 | 4000 | `http://127.0.0.1:4000/` |

## 3. 使用约束
- 以上端口作为 Data-Model 线程的默认运行时基线。
- 如环境端口变更，需先更新本文件版本，再同步到巡检清单与发布说明。
- 端口变更不应被解读为字段语义或指标口径变更。
