现场复核任务

P0

制定主机组合样本采集计划

复核对象
CH4+CH5+CH7 等当前组合及候选组合
责任角色
节能工程师 / 运行值班员
需补数据
组合历史样本 / 当前组合连续运行时间 / 同工况人工切换验证
需提交证据
组合连续运行时长 / 同负荷/湿球 band / 组合 COP / 冷站 COP / 人工切换记录
验收标准
每个候选组合形成 >=30 条低置信可用样本，>=100 条才允许高置信表达。
控制边界
多机运行无单台冷冻水流量时仍只评价组合，不拆单台 COP，不自动启停主机。

复核对象

责任角色
PLC 工程师 / 自控工程师
需补数据
末端阀位/室温/压差 / 支路历史趋势 / 真实 PLC 降泵保护状态
需提交证据
真实 PLC/SCADA 点名 / 回退目标 / 本地联锁 / 最小流量保护 / 频率反馈
验收标准
approve/rollback 点名、反馈点和 PLC 本地保护均完成映射并通过只读核对。
控制边界
未完成前只允许 shadow 记录和人工复核，不允许 assisted/enforced。

需提交证据
点位编号 / 安装位置 / 量程 / 最近校准日期 / 校准责任人
验收标准
形成点位-位置-量程-校准日期-责任人台账，并能对应到 BFF 点位 key。
控制边界
只用于提高诊断置信度，不自动修正测点、不替代现场校验。

P1

补支路水力历史趋势

复核对象
支路流量、支路回水压力、支路供回水温度、旁通阀开度
责任角色
自控工程师 / 水系统调试工程师
需补数据
支路历史趋势 / 末端阀位 / 末端压差 / 代表房间温度
需提交证据
24h 支路趋势 / 采样周期 / 支路与末端区域映射 / 异常窗口标记
验收标准
支路趋势至少覆盖 24h，并能与站级低温差窗口对齐。
控制边界
没有末端阀位/室温时，不直接判定末端阀门故障。
P1

补控制命令/反馈与启停事件台账

复核对象
供水温设定/反馈、泵塔频率命令/反馈、旁通阀命令/反馈、主机/泵/塔启停事件
责任角色
自控工程师 / PLC 工程师
需补数据
高频历史 / 控制命令历史 / PID 参数 / 精确启停事件
需提交证据
高频命令/反馈趋势 / PID/死区/斜率/延时参数 / 精确启停事件 / 最小运行/停机时间
验收标准
命令、反馈、运行状态、启停事件和参数台账可按同一时间轴对齐。
控制边界
只用于复核控制震荡风险，不自动改 PID，不自动启停设备。
P1

补冷却塔现场巡检和长周期分摊

复核对象
塔单元流量、风机频率/功率、阀门状态、填料/布水巡检
责任角色
运行值班员 / 节能工程师
需补数据
塔单元长周期分摊 / 填料/布水现场巡检 / 厂家最低冷凝器进水温确认
需提交证据
塔单元长周期趋势 / 塔阀开到位 / 填料/布水状态 / 最低冷凝器进水温确认
验收标准
塔单元趋势和现场巡检记录可支撑单塔能力差异复核。
控制边界
只作为塔能力诊断证据，不突破厂家/PLC 最低水温保护。

控制震荡台账模板

模板只用于补齐控制震荡诊断证据，不自动改 PID，不自动启停设备，不写真实 PLC。

  • 高频趋势、启停事件和参数台账可按同一时间轴对齐。
  • 采样周期建议 <= 60 秒；若只能小时级，控制震荡仍只能方向性判断。
  • 任何 PID、死区、延时或启停参数调整必须由人工审批和 PLC 本地保护兜底。
