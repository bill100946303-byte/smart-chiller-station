# 多能源站系统 UI 页面责任与数据作用域矩阵

本矩阵用于约束“左侧选对象、顶部选工作区、页面声明真实数据范围”的系统级信息架构。新增页面必须先确定责任层级，再进入导航。

## 1. 导航责任

| 层级 | UI 位置 | 责任 |
| --- | --- | --- |
| 项目 | 顶部项目选择器 | 决定 `siteId` 与全部业务边界 |
| 能源对象/物理站房 | 左侧导航 | 决定当前查看冷冻站、空压站、锅炉房、电力或空调末端；供能站房可继续展开物理实例 |
| 站内功能 | 顶部左侧二级导航 | 当前对象内部的工艺、系统、孪生、日志等页面 |
| 上下文工作区 | 顶部右侧 | 无具体对象关联时显示“项目工作区”，选中站房或配用能系统后显示“能源对象工作区”；必须同时展示关联对象与真实数据范围 |
| 项目配置 | 顶部右侧独立配置入口 | 始终作用于当前项目，不继承 `station` 或 `stationId` |

## 3. UI 验收底线

1. 每个业务页面必须存在一个页面级主标题；沉浸式场景可视觉隐藏，但不能省略语义标题。
2. 关联工作区必须同时显示“关联对象”和“数据范围”，两者不得混为一谈。
3. 不兼容对象必须显示阻断面板，不挂载错误业务页，也不发错误业务请求。
4. 桌面左侧不重复出现值班、分析、AI、诊断和配置大卡片；移动端由同源抽屉手风琴呈现。
5. 900px 以下触控目标不小于 44px；抽屉支持 `Escape` 关闭并把焦点还给触发按钮。
6. `3002` 固定属于项目配置中心，运行端前端回退不得占用该端口。
7. 配用能系统的对象名称不得代替数据范围：电力页显示“当前项目电力汇总”，空调末端页显示“当前楼层末端范围”；配置中心可用也不得等同于实时遥测可用。
8. FCU 控制、消缺、签核与最终控制证据必须同时满足“文件目录按 `siteId` 隔离”和“报告载荷声明相同 `siteId`”；任一条件不满足都不得进入页面或控制门禁。
9. 物理站房上下文中的导航可用性必须与运行范围能力一致；已知不支持 `stationId` 的页面不进入站内导航或工作区计数，类型级入口通过清除实例上下文访问。
10. 项目页不得被标成“站房工作区”；项目级的“总览”与对象级的“运行”必须区分，避免将项目总览误解为某一站房运行页。
11. 仅支持单一能源类型的页面必须显示该类型为关联对象，并使左侧对象选中、右上工作区层级和数据范围三者一致；不得以“无 `station` 查询参数”为由把冷站专属页标成项目页。
