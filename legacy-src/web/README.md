## 开发

```bash
# 克隆项目
git clone  git@gitee.com:shenzhen-shengshi-lvneng/web.git


# 安装依赖
cnpm install
npm install 
yarn install

# 启动服务
npm run dev -- 启动服务
npm run dev:test -- 线上环境
```

## 发布
```bash
# 构建打包代码
npm run build
```

## 代码分支说明
master 是生产分支，不能直接提交，只能从其他分支合并;
dev 是开发分支，拥有最新的代码，开发功能从此分支新建;
